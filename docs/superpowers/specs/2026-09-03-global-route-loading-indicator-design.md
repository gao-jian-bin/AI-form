# 全站路由加载进度条设计

## 要解决的问题

用户从主题列表点击帖子或切换其他站内页面时，页面在路由和数据加载期间没有可见反馈，容易让人误以为点击没有生效。

## 方案

在根组件中使用 Nuxt 自带的 `NuxtLoadingIndicator`。它跟随 Nuxt 路由状态自动开始和结束，不需要修改每一个 `NuxtLink`，也不增加第三方依赖。

进度条固定在浏览器窗口顶部，高度为 3px。正常加载使用站点现有的蓝色 `--tertiary`，加载失败使用 `--danger`。开始导航后短暂延迟 80ms 再显示，避免极快的页面切换产生闪烁。页面加载完成后自动走完并消失。

## 生效范围

- 所有由 Nuxt 接管的站内路由，包括帖子、分类、标签、搜索页和管理页。
- 外部链接、文件下载和当前页面内的普通按钮不触发进度条。
- 不改变现有页面布局，进度条覆盖在页面最上方，不占用内容高度。

## 可访问性与动效

进度条只提供辅助性的视觉反馈，不承载必须通过文字获取的信息，也不抢占焦点。系统启用“减少动态效果”时取消进度条的过渡动画，但仍保留加载状态的颜色提示。

## 测试

增加一条端到端测试：延迟帖子详情接口，点击主题链接后确认顶部进度条可见；接口返回并进入帖子页后，确认进度条消失。随后运行现有测试、类型检查和生产构建。

## 不在本次范围内

- 不显示真实百分比或加载文案。
- 不为普通 API 请求单独显示进度条。
- 不修改帖子页和列表页的数据获取逻辑。
