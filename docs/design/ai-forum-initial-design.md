# AI 论坛 Discourse 风格重构规格

**日期：** 2026-08-20

**参考源码：** `D:\Code\GitHub\discourse`，提交 `c69b1bb8`

## 目标

保留现有 Nuxt、SQLite、公开查询、搜索、Markdown、安全认证和私有管理工作台，将公共网站重构为轻量的 Discourse 前端复刻。复刻重点是官方源码中的布局、主题表格、导航、分类元数据和响应式行为，不运行或移植 Rails、PostgreSQL、Redis、Sidekiq 及完整社区功能。

## 源码依据

- `app/assets/stylesheets/common/base/header.scss`：固定顶部栏、高度、阴影和图标尺寸。
- `app/assets/stylesheets/common/base/sidebar.scss`：17em 侧栏、分区链接、边框与选中状态。
- `app/assets/stylesheets/common/base/discourse.scss`：1110px 内容宽度、侧栏网格和主题列表令牌。
- `frontend/discourse/app/components/topic-list/list.gjs`：主题表格及可配置列结构。
- `frontend/discourse/app/components/topic-list/item/topic-cell.gjs`：标题、分类和标签的两行信息层级。
- `app/assets/stylesheets/common/base/_topic-list.scss`：主题行间距、字体、表头、数值列和移动端规则。
- `app/assets/stylesheets/common/base/list-controls.scss`：分类选择器、导航标签和操作区。
- `app/assets/stylesheets/common/foundation/colors.scss`：默认 `#222`、`#fff`、`#08c` 基础色。

## 保留范围

- ChatGPT、工具箱两个一级板块
- 最新主题、分类筛选、标签筛选和全文搜索
- Markdown 主题详情与工具外链
- 私有站长登录、草稿、发布、编辑、置顶和删除
- SQLite、Docker、SEO、站点地图、测试和部署文档

主题管理列表保持现有结构；新建和编辑界面改为 Discourse Composer 风格。

## 删除的视觉元素

- 网格纸背景
- “知识轨道”竖线和节点
- 首页巨大标题及英文眉题
- 右侧“关于这里”“热门主题”等宣传侧栏
- 大段主题摘要
- 大面积卡片、渐变、阴影和装饰性文案
- 主题详情页的超大 Hero 标题

## 公共页面结构

### 顶部栏

- 约 52px 高的白色固定栏，底部使用轻阴影。
- 左侧依次为侧栏按钮和纯文字站点标识。
- 右侧只有搜索与浅色/深色切换。
- 不显示登录、注册或公开发帖按钮。
- 手机端点击搜索直接进入搜索页；侧栏以抽屉形式打开。

### 全局布局

```text
┌──────────────────────────────────────────────────────┐
│ ☰  AI 知识论坛                              搜索  ◐  │
├──────────────┬───────────────────────────────────────┤
│ 帖子         │ [所有分类⌄] [所有标签⌄]  最新          │
│  最新帖子    │                                       │
│              │ 主题                    浏览     活动  │
│ 分类         │ ───────────────────────────────────── │
│  ChatGPT     │ 📌 主题标题             128      2h   │
│  工具箱      │ ■ ChatGPT  prompt · 工作流            │
│              │ ───────────────────────────────────── │
│ 标签         │ 工具标题                 56      昨天  │
└──────────────┴───────────────────────────────────────┘
```

- 桌面侧栏宽度为 17em，主内容最大宽度约 1110px。
- 不设置右侧栏。
- 页面背景为纯色，主内容与侧栏只使用细边框分隔。
- 低于平板断点时，侧栏变成覆盖式抽屉，主内容占满宽度。

### 主题导航

- 分类选择器用于切换全部、ChatGPT 和工具箱。
- 标签选择器与侧栏使用独立的全站标签数据，不依赖当前筛选结果。
- “最新”作为当前列表标签。
- 分类页在导航上方显示小型分类说明，不使用大标题 Hero。
- 侧栏“帖子”分区只显示“最新帖子”，不显示搜索入口。
- 侧栏标签分区默认折叠；打开标签页后完整标签列表仍然保留，当前标签只做高亮。

### 主题列表

使用语义化 `<table>`：

- 桌面列为“主题 / 浏览 / 活动”。
- 不显示回复数和用户头像，因为初版没有普通用户和回复。
- 标题为第一行；分类色块、分类名、标签和可选工具域名位于第二行。
- 置顶主题使用图钉图标，不额外放置彩色“置顶”胶囊。
- 默认列表不显示摘要。
- 行只使用水平分隔线和极轻的悬停背景。
- 手机端每个主题行成为整行点击区域，标题下显示分类、标签、浏览量和活动时间。

### 主题详情

- 使用与列表相同的全局侧栏。
- 标题保持论坛尺度，约 30–34px。
- 标题下显示分类、标签、发布时间和浏览量。
- 正文采用 Discourse 帖子流结构：左侧作者头像，右侧作者信息与正文。
- 工具外链使用普通主按钮。
- 相关文章以简化主题表格呈现。

### 管理编辑器

- 新建和编辑帖子使用停靠在页面底部的 Discourse Composer 式面板。
- 顶部依次放置帖子标题、分类和可选标签。
- 桌面端 Markdown 输入与安全预览左右分栏，手机端允许切换编辑/预览。
- 底部工具栏提供粗体、斜体、链接、引用、代码、无序列表、有序列表和标题操作。
- 底部右侧提供保存草稿与发布按钮；现有服务端草稿和发布接口保持不变。
- 工具栏配置和常用文案集中在独立文件中，方便后续自行修改。

## 配色与排版

- 浅色：`#ffffff` 页面、`#222222` 主文字、`#0088cc` 主操作、`#e9e9e9` 分隔线。
- 深色：保持相同层级关系，不增加渐变和发光效果。
- 使用系统无衬线字体栈，正文 14–15px，主题标题约 16–17px。
- 元数据使用 12–13px 灰色文本。
- 圆角只用于按钮、下拉框和侧栏选中状态，主题表格本身无卡片圆角。

## 行为与权限

- 访客只能浏览、搜索和打开外部工具。
- 公共页面不出现登录、注册、回复或新建主题入口。
- 管理 API、草稿隔离、Markdown 清理和会话逻辑保持现有实现。
- 不创建虚假的回复、成员、在线状态或头像数据。

## 验收

- 1440px 截图应明显接近 Discourse 默认桌面布局，而不是博客或 AI 落地页。
- 390px 截图应采用 Discourse 移动主题行结构，没有横向滚动。
- 公共首页不得出现当前版本的网格、右栏、知识轨道和巨大标题。
- 桌面主题表头必须显示“主题、浏览、活动”。
- 主题详情必须呈现作者栏加正文的帖子结构。
- 现有单元测试、类型检查、生产构建和端到端测试全部通过。
