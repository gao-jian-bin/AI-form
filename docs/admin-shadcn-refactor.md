# 后台重构：shadcn-admin 适配

## 范围与边界

- 将 shadcn-admin（参考版本 e16c87f）的侧栏、工具栏、Slate 主题、卡片和表格体系适配到 Nuxt 4 / Vue 3，不引入第二套 React 应用。
- 后台共 13 个路由：概览、帖子列表、板块列表/新增/编辑、标签列表/新增/编辑、图片、访问统计、登录，以及两个保持兼容的帖子编辑器入口。
- 保留 `/admin` 的帖子管理入口、全部 `/api/studio/*` 接口、数据库结构和公开站点样式。无数据库迁移。
- Markdown Composer 保留原有保存、预览、上传、拖拽、草稿恢复、发布时间、浏览量调整、历史版本、全屏和未保存保护功能，后台使用统一的主题配色。

## 使用

- 左侧按工作空间、内容管理、资源与数据分组；桌面可收起侧栏，手机使用带焦点锁定与 Escape 关闭的抽屉。
- 顶部搜索或 Ctrl/Cmd + K 打开快速导航，也可按帖子标题搜索。
- 顶部切换深浅色；主题沿用公共网站的本地偏好。退出登录在侧栏底部。
- 帖子每页 20 条，支持状态、板块、标题和排序；板块、标签支持搜索和分页，图片每页 12 张，访客每页 20 条。
- 概览只展示真实数据，内容分布按板块统计，不展示模板中的模拟销售额或虚构趋势。
- 删除仍保留明确确认，加载与操作失败在页面显示，批量图片清理会报告部分失败。

## 实现

- `app/layouts/studio.vue`：外壳、移动抽屉、快速搜索与退出。
- `app/assets/css/studio.css`：限定于后台的设计令牌和响应式样式。
- `app/components/Studio*.vue`：导航、页面标题、统计、空状态和分页。
- `app/composables/useStudio*.ts`：主题和分页逻辑。
- Reka UI 提供 Dialog 的焦点管理，@lucide/vue 提供按需图标。上游 MIT 许可见 THIRD_PARTY_NOTICES.md。

## 验证和发布

使用 `npm test`、`npm run typecheck`、`npm run build` 和 `node scripts/run-e2e.mjs` 验证。后者使用临时数据库，不写入本地或线上内容库。

发布沿用 docs/deployment-workflow.md：提交推送 → 记录旧版本 → 备份线上数据库和图片 → 拉取已验证提交 → 重建容器 → 检查 health 与公开路由。失败时回退到发布前提交，保留数据，不覆盖现有 .env。
