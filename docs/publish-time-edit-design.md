# 帖子发布时间手动修改设计

管理员发布帖子时，发布时间仍默认使用当前时间。编辑已发布帖子时，在 Composer 的“更多设置”中显示原发布时间，并允许管理员手动修改。

- 复用 SQLite 已有的 `published_at` 字段，不迁移数据库。
- 浏览器使用本地 `datetime-local` 输入，提交时转为 ISO 时间。
- 留空则维持正常自动逻辑；手动填写则覆盖原发布时间。
- 不接受未来时间，不实现定时发布。
- 公共帖子列表继续按 `published_at` 排序，修改时间后自然重新排序。
- 后台列表仍按最后更新时间排序。
- 服务端负责最终校验，测试覆盖默认时间、手动覆盖、未来时间拒绝和编辑器回填。
